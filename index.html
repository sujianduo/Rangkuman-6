Apa itu Sistem Komputer & Bagian Utamanya?

Bab 3 - Konsep Dasar

Pengertian Sistem Komputer

Kumpulan perangkat komputer yang saling berhubungan dan berinteraksi satu sama lain untuk menjalankan tugas serta mengolah data menggunakan komputer.

3 BAGIAN UTAMA SISTEM KOMPUTER:

1. Hardware

Perangkat Keras fisik yang tampak & dapat disentuh (Keyboard, CPU, Monitor).

2. Software

Perangkat Lunak berupa program/aplikasi yang mengontrol jalannya sistem.

3. Brainware

Pengguna/manusia yang mengoperasikan & mengendalikan komputer.

Pembagian Software Berdasarkan Fungsinya

Klasifikasi Software

Software (Perangkat Lunak) dibagi menjadi 3 kelompok utama sesuai tugas & perannya:

1

System Software (Sistem Operasi / OS)

Perangkat lunak utama yang mengendalikan seluruh sumber daya komputer & menghubungkan hardware dengan pengguna.
Contoh: Microsoft Windows, Linux, macOS, Android, iOS.

2

Utility Software (Perangkat Lunak Pengatur)

Berfungsi membantu mengoptimalkan, merawat, dan mengamankan kinerja komputer.
Contoh: Antivirus, Cleaner, Firewall, Disk Defragmenter.

3

Application Software (Perangkat Lunak Aplikasi)

Software khusus yang dibuat untuk membantu pekerjaan spesifik atau hiburan pengguna.
Contoh: Microsoft Word, Excel, Google Chrome, Mobile Legends.

Hirarki Urutan Kerja Perangkat Lunak

Struktur Hirarki

Perangkat lunak bekerja berdasarkan hirarki tingkatan dari lapisan terbawah hingga lapisan terluas:

1

System Software

Fondasi utama yang langsung mengontrol Hardware komputer.

2

Utility Software

Merawat, menjaga, dan mengoptimalkan fungsi sistem.

3

Application Software

Aplikasi akhir yang langsung dipakai pengguna untuk bekerja.

Urutan Hirarki = system software → utility software → application software

Contoh Sistem Operasi (Operating System / OS)

Sistem Operasi

Sistem Operasi Komputer

  • Microsoft Windows (Populer buatan Microsoft)
  • Linux (Sistem operasi open-source gratis)
  • macOS (Sistem operasi khusus perangkat Apple)

Sistem Operasi Smartphone

  • Android (Paling banyak digunakan pada smartphone)
  • iOS (Sistem operasi khusus iPhone/iPad)

Antarmuka Pengguna: GUI vs CLI

User Interface

1. GUI (Graphical User Interface)

Antarmuka Berbasis Grafis Visual

  • Menggunakan visual grafis: tombol, ikon, cursor, dan menu.
  • Sangat mudah digunakan pengguna umum (User-friendly).
  • Cukup klik dengan mouse/sentuhan tanpa hafalan perintah.

2. CLI (Command Line Interface)

Antarmuka Berbasis Baris Perintah Teks

  • Pengguna harus mengetikkan baris perintah kode khusus.
  • Hanya menampilkan layar hitam berisi tulisan teks tanpa grafis.
  • Membutuhkan hafalan kode/perintah sistem secara presisi.

Elemen Visual Utama Pada Antarmuka GUI

Komponen GUI

Desktop

Tampilan halaman utama layar komputer saat pertama kali dinyalakan.

Ikon (Icon)

Simbol / gambar kecil visual yang mewakili aplikasi, berkas, atau folder.

Taskbar

Bilah panjang di bagian bawah layar tempat ikon aplikasi yang sedang aktif.

Cursor (Kursor)

Penunjuk posisi pada layar yang digerakkan menggunakan mouse atau touchpad.

Keunggulan GUI Dibandingkan CLI

Keunggulan GUI

1. Mudah Digunakan (User Friendly)

Pengguna tidak perlu menghafal ratusan kode/perintah baris teks seperti pada CLI.

2. Tampilan Visual Menarik & Interaktif

Dilengkapi warna, tombol, gambar, ikon, dan animasi yang memperjelas fungsi aplikasi.

3. Efisiensi & Kecepatan Interaksi Navigasi

Pengguna cukup mengklik atau menyentuh layar tanpa takut salah mengetik huruf instruksi.

Manajemen File & Folder pada Windows

File & Folder

File (Berkas)

Unit penyimpanan data/informasi digital (seperti dokumen .docx, gambar .jpg, lagu .mp3).

Folder (Direktori)

Wadah/tempat penyimpanan digital untuk mengelompokkan beberapa berkas agar rapi & teratur.

Langkah-Langkah Membuat Folder Baru di Windows:

1. Klik kanan pada area kosong 2. Pilih menu New 3. Pilih Folder

Melihat Spesifikasi Komputer di Windows

System Settings

Untuk mengetahui jenis prosesor, kapasitas RAM, serta versi Windows yang digunakan pada komputer, ikuti langkah akses menu berikut:

1. Windows Menu

2. Setting

3. System

4. About

Urutan Kunci: Windows < Setting < System < About
